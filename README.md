## Cartografia de uma presença: literatura e visualização de dados

Tenho interesse pelas relações entre tecnologia, memória, narrativas e produção de conhecimento.

Em *Cartas a uma negra*, a escritora martinicana Françoise Ega dirige cartas a Carolina Maria de Jesus, escritora brasileira que reconhece como inspiração. A presença de Carolina atravessa a obra e foi o ponto de partida para este projeto de visualização de dados.

Desenvolvi **Cartografia de uma presença** como parte dos meus estudos em **Data Visualization (DataViz)**. A proposta é observar como as referências a Carolina Maria de Jesus se distribuem ao longo das páginas do livro, transformando essa recorrência em uma experiência visual e interativa.

A partir de dados extraídos por OCR (reconhecimento óptico de caracteres) e organizados em um arquivo CSV, desenvolvi a visualização com **JavaScript e p5.js**.

Cada ponto representa uma página da obra. As cores distinguem páginas com e sem ocorrências do nome Carolina, enquanto o tamanho dos pontos varia conforme a quantidade identificada. Uma animação em ondas atravessa a composição, e a interação permite selecionar cada ponto para consultar a página e o número de ocorrências registradas.

O projeto é um exercício de aproximação entre leitura literária, análise de dados e programação criativa: uma maneira de observar visualmente como a presença de uma escritora se manifesta ao longo da obra de outra.

**Tecnologias:** JavaScript · p5.js · CSV · OCR · GitHub Pages
